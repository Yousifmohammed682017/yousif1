### 🌟 الميزات والتحديثات المنفذة في هذا الإصدار:

1. **الشعار الحقيقي المعتمد للهلال الأحمر السوداني (`images/srcs-logo.png`)**:
   - تم استبدال كافة الرسومات والشعارات السابقة بالشعار الحقيقي الرسمي لجمعية الهلال الأحمر السوداني المرفق من قبل الإدارة.
   - **في أعلى هامش الصفحة:** شريط ترويسة سيادي فاخر يحمل الشعار الرسمي الحقيقي، اسم الجمعية باللغتين العربية والإنجليزية، وسام "فرع الولاية الشمالية"، تأكيد التغطية للمحليات السبع، وهاتف طوارئ الرئاسة المباشر.
   - **في القائمة الجانبية وشاشة قفل المشرفين:** دمج الشعار الرسمي الحقيقي في إطارات نقية بيضاء مع شارات رسمية متوهجة.
   - **أيقونة الموقع (Favicon & App Icon):** تم ضبط أيقونة المتصفح واختصار تطبيقات الهاتف المحمول (PWA Manifest) لتستخدم الشعار الحقيقي المعتمد.

2. **مرونة كاملة في التعديل على المنصة دون الرجوع للكود (No-Code CMS)**:
   تم إنشاء تبويب مركزي متكامل في لوحة المشرفين تحت اسم **`محتوى وهوية المنصة والمحليات (CMS)`** يتيح لإدارة الفرع تعديل المنصة فورياً وتخزين البيانات محلياً دون الحاجة لتعديل ملفات HTML/JS:
   - **محرر شريط الأخبار العاجلة (Breaking Ticker):** إضافة وحذف وتعديل الأخبار العاجلة التي تسير في الشريط الأحمر بأعلى الصفحة الرئيسية.
   - **محرر إحصائيات وإنجازات الاستجابة الإنسانية (Impact Statistics):** تعديل عدد المحليات، إجمالي الأسر المستفيدة، نسبة تغطية الطوارئ، عدد المتطوعين، طرود المساعدات، وأقراص تعقيم المياه وتنعكس فوراً في الواجهة.
   - **محرر بيانات وتواصل المحليات السبع:** تعديل هاتف الطوارئ، رقم الواتساب الميداني، اسم المنسق، العنوان، وعدد المتطوعين لكل محلية من المحليات السبع على حدة (دنقلا، مروي، الدبة، القولد، وادي حلفا، البرقيق، دلقو).
   - **محرر التصنيفات الإخبارية:** إمكانية إضافة تصنيفات جديدة للمشرفين (مثل رعاية صحية، إغاثات، أمن غذائي، مياه وإصحاح، إلخ) وحذف التصنيفات المخصصة.
   - **محرر هواتف وروابط الطوارئ المركزية:** تعديل هواتف الرئاسة والبريد الإلكتروني للفرع.

3. **حزمة خيارات الأمان المتقدمة لصفحة الإدارة (`admin.html`)**:
   - **شاشة قفل المشرفين (Security Gatekeeper):** محمية ببريد المشرف، رمز المرور (PIN)، ورمز المصادقة الثنائية 2FA.
   - **حماية القفل التلقائي ضد التخمين (Brute-Force Lockout):** تعليق الدخول مؤقتاً لمدة 5 دقائق عند إدخال الرمز خطأ 5 مرات، مع عداد تنازلي لحظي ومؤشر محاولات متبقية.
   - **وضع الإغلاق الأمني والطارئ (Emergency Security Lockdown Mode):** مفتاح رئيسي للمدير العام لتفعيل حالة الطوارئ القصوى بالمنصة، وإظهار شريط تحذيري أحمر للزوار، وتجميد نشر المقترحات العامة غير المباشرة.
   - **مهلة الجلسة والقفل التلقائي القابل للتخصيص:** خيارات مرنة لمدة الجلسة (5 دقائق أمان مشدد، 15 دقيقة موصى به، 30 دقيقة، ساعتان للمناوبات الطويلة)، مع عداد تنازلي لحظي في الشريط العلوي وزر تمديد الجلسة.
   - **إدارة المصادقة الثنائية (2FA) ومولد رموز الإنقاذ الاحتياطية:** توليد 10 رموز إنقاذ للطوارئ (One-Time Rescue Codes) مع مفتاح أمان متوافق مع تطبيقات Google Authenticator و Microsoft Authenticator.
   - **إدارة صلاحيات المشرفين (RBAC):** إضافة، تعديل، تجميد، وحذف المشرفين، وتوزيع الأدوار (مدير عام، مشرف طوارئ، مسؤول نشر، مراجع).
   - **سجل التدقيق الأمني (Audit Log):** تسجيل زمني مشفر لكافة عمليات الدخول، التعديلات، والتحديثات.

4. **خريطة الانتشار التفاعلية لمحليات الولاية السبع (Interactive Leaflet Map)**:
   - خريطة جغرافية دقيقة تغطي كافة محليات الولاية الشمالية السبع بنقاط ارتكاز دائرية وعناوين وهواتف طوارئ.
   - زر الرجوع خطوة للخلف (`زر العودة للمنصة الرئيسية`) مع شريط مسار (Breadcrumbs) تفاعلي.

5. **الملف التعريفي للجمعية والمبادئ السبعة الأساسية**:
   - صفحة كاملة تشرح تاريخ وتأسيس فرع الولاية الشمالية، والمبادئ السبعة للحركة الدولية (الإنسانية، عدم التحيز، الحياد، الاستقلال، الخدمة التطوعية، الوحدة، العالمية) مع إمكانية تعديلها بالكامل من لوحة التحكم.

### 🚀 جاهزية الملف للرفع على الإنترنت (Web Deployment Guide):

الملف مصمم ليكون **ثابتاً بنسبة 100% (Static Single-Page / Multi-Page App)** ولا يحتاج لأي خادم Node.js أو قاعدة بيانات SQL خلفية ليعمل؛ يعمل فور فك الضغط على أي استضافة عالمية:

#### الطريقة الأولى: الرفع المباشر عبر Netlify Drop (المجانية الأسرع - دقيقة واحدة)
1. افتح موقع [app.netlify.com/drop](https://app.netlify.com/drop).
2. اسحب ملف الأرشيف النهائي `srcs-northern-state-final.zip` (أو المجلد المفكوك) وأفلته في المربع.
3. ستحصل فورياً على رابط مباشر دائم للمنصة (مثل `srcs-northern.netlify.app`) بشهادة أمان SSL خضراء مجاناً.

#### الطريقة الثانية: الرفع عبر GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على GitHub وسمّه `srcs-northern-state`.
2. ارفع كافة الملفات إلى الفرع الرئيسي `main`.
3. اذهب إلى `Settings` -> `Pages` واختر `Deploy from a branch` -> `main` / `root`.
4. سيتم نشر الموقع عالمياً في ثوانٍ.

#### الطريقة الثالثة: الرفع على استضافة خاصة (cPanel / Apache / Nginx / Hostinger)
1. ادخل إلى لوحة التحكم `cPanel` الخاصة بالدومين الخاص بكم.
2. توجه إلى `File Manager` -> مجلد `public_html`.
3. اضغط `Upload` وارفع ملف `srcs-northern-state-final.zip`.
4. اضغط زر الفأرة الأيمن على الملف ثم اختر `Extract` (فك الضغط في نفس المجلد).
5. سيصبح الموقع متاحاً على النطاق مباشرة عبر أي متصفح في العالم.
